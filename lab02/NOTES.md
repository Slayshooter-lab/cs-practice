# Git и GitHub

Рабочая папка — это директория на компьютере, где хранятся файлы проекта.
Индекс (staging area) — промежуточная область, куда добавляются изменения перед коммитом.
Коммит — это зафиксированное состояние файлов в истории репозитория.

## Разница между Git и GitHub
Git — это локальная система контроля версий, работающая на компьютере.
GitHub — это облачный сервис для хранения удаленных репозиториев.

## Использованные команды
git status — показывает состояние рабочей папки и индекса.
git diff — показывает разницу между рабочей папкой и индексом.
git diff --staged — показывает разницу между индексом и последним коммитом.

## Ветки
Ветка — это указатель на определенный коммит. При создании нового коммита указатель сдвигается вперед.
Слияние (merge) — это перенос изменений из одной ветки в другую.
