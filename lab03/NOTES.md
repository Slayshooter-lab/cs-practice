## Сравнение версий и поиск изменений
- `git diff` показывает незакоммиченные изменения (рабочая папка vs индекс).
- `git show` показывает полную информацию о конкретном коммите (кто, когда, какие изменения).
- `git log` показывает историю коммитов.
- С помощью `git log -S"def"` я нашел коммиты, где добавлялись функции (сложение, вычитание, умножение).
- `git blame` показал, какой коммит и автор отвечает за каждую строку в calc.py.

## Восстановление файла
- `git restore <файл>` отменяет изменения в рабочей папке и возвращает файл из последнего коммита. Это спасает, если случайно удалил код и не закоммитил.
- `git restore --source=HEAD~2 <файл>` берет версию файла из конкретного коммита (в данном случае 2 коммита назад) и кладет ее в рабочую папку. Это полезно, чтобы посмотреть, как код выглядел раньше.
